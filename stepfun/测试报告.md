# 测试报告

全部数据来自提交应用的页面内基准测试（`window.__KB__.bench()`），由 `bench/run-bench.mjs`
驱动本机 Chrome 自动执行并落盘到 `bench/results/`，不是手工填写。

## 1. 环境与测试集

- 设备：Apple Silicon macOS，GPU 后端 Metal-3
- 浏览器：Chrome 156（headless=new），WebGPU 可用（`vendor=apple`）
- Node.js 25.9.0，seekdb-js 1.4.0（嵌入式文件模式）
- 模型：`Xenova/bge-small-zh-v1.5`（512 维，CLS + L2）
- 语料：`public/corpus/corpus.json`，30 篇中文技术短文，3317 字，按 240 字符 / 40 重叠切分为 30 块
- 查询：`public/bench/queries.json`，12 条查询，人工标注 1–2 个相关文档
- 指标：文档级 Recall@5、nDCG@5、MRR@10；时延取 12 次查询中位数
- 每个配置：先加载模型 → 向量化 3 轮取中位 → upsert + `refresh_index()` → 12 条查询
  （查询向量化、seekdb 检索、端到端分别计时）

## 2. 四种配置实测

| 配置 | 模型体积 (MiB) | 加载 (ms) | 文档向量化首次/中位 (ms) | 吞吐 (字/秒) | 写入 (ms) | 刷新 (ms) | 查询向量化中位 (ms) | 检索中位 (ms) | 端到端中位 (ms) | Recall@5 | nDCG@5 | MRR@10 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| fp32 + wasm | 90.5 | 4026 | 1591 / 1559 | 2127 | 72 | 324 | 8.9 | 2.19 | 13.2 | 1.000 | 0.974 | 0.958 |
| q8 + wasm | 22.9 | 232 | 1625 / 1596 | 2078 | 70 | 428 | 10.2 | 2.09 | 14.1 | 1.000 | 0.974 | 0.958 |
| fp16 + webgpu | 45.3 | 387 | 107 / 73 | 45314 | 77 | 426 | 9.0 | 2.27 | 13.4 | 1.000 | 0.974 | 0.958 |
| q8 + webgpu | 22.9 | 217 | 1657 / 1642 | 2020 | 80 | 318 | 20.1 | 2.30 | 24.4 | 0.750 | 0.600 | 0.586 |

要点：

- INT8 + WASM 与 fp32 基线质量完全一致（Recall@5 = 1.000），模型体积从 90.5 MiB 降到 22.9 MiB（3.95×）。
- FP16 + WebGPU 质量一致，文档向量化吞吐 45.3k 字/秒，是 WASM 的 21 倍。
- INT8 + WebGPU 质量下降到 0.750 / 0.600：ORT 日志显示部分量化算子未分配到 WebGPU EP，
  回退 CPU，吞吐没有收益（2.0k 字/秒）且数值路径变化。因此界面默认「WebGPU→fp16，WASM→q8」。

## 3. 冷启动 vs 预热

禁用 HTTP 缓存、全新 Chrome 配置下测量（`bench/perf-extra.mjs`）：

| 配置 | 冷启动（会话创建+编译） | 预热后重新加载 |
| --- | --- | --- |
| q8 + WASM | 6125 ms | 232 ms |
| fp16 + WebGPU | 4130 ms | 387 ms |

首次冷启动还包含 ONNX Runtime wasm（21.6 MB）下载与模型权重下载；本地模型目录下这部分走 localhost。

## 4. 批大小对照

同一 30 条语料、3 轮取中位：

| 配置 | 批大小 | 中位耗时 (ms) | 吞吐 (字/秒) |
| --- | --- | --- | --- |
| q8-wasm | 1 | 1419.4 | 2337 |
| q8-wasm | 8 | 1559.8 | 2127 |
| q8-wasm | 16 | 1585.4 | 2092 |
| q8-wasm | 32 | 1642.1 | 2020 |
| fp16-webgpu | 1 | 230.4 | 14397 |
| fp16-webgpu | 8 | 87.5 | 37909 |
| fp16-webgpu | 16 | 70.9 | 46784 |
| fp16-webgpu | 32 | 70.5 | 47050 |

FP16 + WebGPU 从批 1 的 14.4k 字/秒提升到批 16 的 46.8k（3.2×），批 32 无进一步收益，默认取 16；
WASM 端批处理无收益（单线程 SIMD 已饱和），略大反而因内存拷贝变慢。

## 6. 复现命令

```bash
cd stepfun
npm install
node scripts/fetch-models.mjs        # 或 MODEL_HOST=https://modelscope.cn/models MODEL_REVISION=master
npm run dev                          # API :8787 + Web :5173

node scripts/smoke.mjs               # 数据层冒烟
APP_URL='http://localhost:5173/?autoload=0' node bench/run-bench.mjs q8 wasm fp16 webgpu
node bench/perf-extra.mjs            # 冷启动 + 批大小
node bench/e2e.mjs                   # UI 端到端 + 截图 docs/ui.png
```
