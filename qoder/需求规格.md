# 知栈 StudyStack — 需求规格（交给 Qoder 执行）

## 背景与痛点
学生复习时笔记散落在多个 Markdown/TXT 文件里，找不到对应知识点；也不知道自己哪些地方薄弱。
本项目建设一个**本地优先的课程笔记复习助手**：笔记只在浏览器与本机 seekdb 中处理，不上传云端。

## 目标用户与场景
- 大学生 / 研究生，按课程维护笔记
- 期末复习：输入问题 → 混合检索定位笔记原文 → 标记掌握度 → 下次优先复习薄弱点

## 功能需求（必须全部实现）
1. **多课程知识库**：每个课程一个 seekdb collection，可新建、切换、删除；显示文档数/分块数/维度。
2. **导入笔记**：支持 .md/.txt/.json（数组 {id,title,text}）多文件导入；按句子边界分块（可配置大小/重叠）；
   在浏览器 Web Worker 中用 Transformers.js（模型 Xenova/bge-small-zh-v1.5，dtype q8，WebGPU 优先、失败降级 WASM）
   计算向量；把向量、原文、元数据写入 seekdb。
3. **混合检索**：查询向量同样在浏览器本地计算；检索必须在 seekdb 内完成
   （服务端调用 DBMS_HYBRID_SEARCH，单条 SQL 内做全文 MATCH + 向量距离 + RRF 融合）；
   返回排序结果、得分、原文与来源文件；前端高亮命中词。
4. **复习与掌握度（记忆能力）**：检索结果可“加入复习”；对知识点标记 会/模糊/不会，
   写入 seekdb 的 `review_progress` 表（结构化 SQL 表）；首页展示薄弱知识点 Top 5（按掌握度升序、复习次数降序），
   支持“再次复习”跳回对应笔记。
5. **状态管理**：当前课程、导入进度、最近一次检索耗时（查询向量化/seekdb 检索/端到端）都要可见；
   刷新页面后当前课程与复习进度保持。
6. **错误与边界**：未加载模型、未选课程、维度不一致、空查询都要有明确提示；导入中断不破坏已有数据。

## 技术要求
- 前端：Vite + TypeScript，原生 DOM（不引入 React），深色简洁 UI，中文界面
- 后端：Node.js + Express + seekdb-js 1.4.0 嵌入式模式（SEEKB_PATH=./data/study.db）
- 向量维度 512（bge-small-zh-v1.5）；seekdb collection schema：
  fulltextIndex = ngram(ngram_token_size=2)，vectorIndex = HNSW cosine，embeddingFunction=null
- 混合检索：`SET @search_parm` + `DBMS_HYBRID_SEARCH.GET_SQL` + 执行返回 SQL；
  嵌入式构建需去掉生成 SQL 中的 APPROXIMATE 关键字（精确扫描），融合仍在库内完成
- 模型文件默认从 `/models` 本地目录加载（服务端静态托管 models/），可用 MODEL_HOST 覆盖
- 端口：API 8787，Vite 5173，/api 与 /models 代理到 8787

- README：安装、启动、seekdb 部署方式、验证样例（含预期结果）
- 代码结构清晰，含 .gitignore（node_modules、dist、data、models）
